## Параметры API

| Параметр | Тип данных | Обязательный | Описание |
| :--- | :--- | :---: | :--- |
| `userId` | integer | Да | Уникальный идентификатор пользователя |
| `role` | string | Нет | Роль пользователя в системе |
| `isActive` | boolean | Нет | Статус активности аккаунта |

> **Примечание:** Если параметр `role` не указан, по умолчанию присваивается роль "guest".

> **Внимание!** Все запросы должны содержать заголовок `Authorization`.```
